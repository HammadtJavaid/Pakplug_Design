# Driver flow specs (2026-10-04 overnight run)

One spec per flow, researched against the logic map and Mobbin, then reviewed by a coverage critic. `00-system.md` is the single design language every flow follows (navigation, motion and haptics, shared components, section plan, consistency rules, resolved conflicts).

| File | Flow |
|---|---|
| `00-system.md` | Shared design language, components to build, section and frame plan |
| `01-onboarding.md` | Splash, story, sign in, create account, verify email, log in, reset, role, first vehicle, permissions, all set |
| `02-discover.md` | Home map and list, station cards, location states, saved chargers, price trends |
| `03-search.md` | What drivers can search, how, every state and micro-interaction; filter & sort |
| `04-station-book.md` | Place sheet, details, reviews, directions, book a slot, vehicle, confirm, errors |
| `05-charge-start.md` | Charge tab, QR and code, battery level, charge planner (time or target estimate), start, connect |
| `06-live-complete.md` | Live charging, stop, accessory, Lock Screen and Dynamic Island, complete, receipt, rating |
| `07-bookings.md` | Charging Passes in every status, empty/loading/errors, pass detail, cancel, Wallet |
| `08-profile-vehicles.md` | Profile, identity, vehicles (add, edit, delete), edit profile, notifications, settings, sign out |
| `09-messages.md` | Inbox, chat thread, inquiries, options and call |
| `BUILD-BRIEF.md` | The brief the Figma builders work from (tokens, component IDs, screen template, doc format, dummy data) |
